AboutCode created Package-URL (PURL), the universal identifier for software
packages now used across CycloneDX, SPDX, CSAF, OpenVEX, OSV, MITRE CVE,
and many more standards. AboutCode also created VERS for version ranges and
contributes to CycloneDX and co-founded SPDX.

PURL is the common thread that ties SBOMs, vulnerability databases, security
advisories, and attestations together.
